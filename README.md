# Vara City Explorer

Build a complete interactive website called "Vara City".

IMPORTANT:

This is NOT a normal Web3 landing page.

It should feel like an interactive illustrated city that people can explore.

The user enters Vara City, walks/explores through a simple illustrated environment, clicks buildings and stores, enters them, learns about Vara Network features, and discovers real projects built on Vara.

The experience should feel similar to an interactive animated travel/simulator website.

1. PRIMARY VISUAL REFERENCE

━━━━━━━━━━━━━━━━━━━━

Use the provided Vara City illustration as the main visual reference.

The visual style must STRICTLY follow the style of the previous Safar-e-UP website.

Safar-e-UP visual language:

- flat 2D illustration

- hand-painted/editorial illustration feel

- slightly imperfect shapes

- subtle paper/grain texture

- simple but detailed environments

- strong foreground / midground / background separation

- cinematic framing

- people naturally placed inside the environment

- buildings that feel like real places

- large readable environmental typography

- subtle parallax

- smooth camera movement

- clickable objects

- immersive scene transitions

- simple UI

- lots of visual breathing room

DO NOT turn this into:

- generic Web3 design

- cyberpunk

- futuristic 3D city

- glassmorphism

- dashboard UI

- card-grid website

- excessive gradients

- excessive neon

- floating crypto coins

- complex 3D models

- complicated maps

- overly dense city

- giant walls of text

The experience should feel like:

"I am visiting a small illustrated city."

NOT:

"I am looking at a Web3 dashboard."

Do not use instant page changes.

2. camera moves toward building

3. foreground moves faster

4. background moves slower

5. building fills viewport

6. information scene appears

Transition duration:

600–1000ms.

Use smooth easing.

When clicking:
